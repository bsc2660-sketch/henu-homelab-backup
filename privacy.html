개인정보 처리 안내

이 앱은 홈랩 소유자 본인이 운영하는 개인 백업 도구입니다. 공개 회원가입이나 타인의 백업을 받는 기능은 없습니다.

처리하는 정보와 목적

소유자가 선택한 백업의 암호화된 내용, 백업 파일 식별자와 크기·시각, 저장공간 사용량 및 전송 결과를 백업·복원·오류 확인 목적으로 처리합니다. Google 계정 정보는 올바른 백업 계정인지 확인하는 데 사용할 수 있습니다.

Google Drive의 drive.file 권한으로 이 앱이 만들거나 소유자가 이 앱에 허용한 파일의 생성·조회·수정·삭제를 수행할 수 있습니다. 이는 기존 Drive 전체 파일에 대한 접근 권한이 아닙니다. 실제 백업 보존·정리는 소유자의 설정과 지시에 따릅니다.

저장과 보호

백업 내용은 로컬에서 restic으로 암호화한 뒤 소유자의 Google Drive에 저장합니다. OAuth 인증 자료와 복구 암호는 소유자의 장치에서 접근 권한을 제한해 보관하며 이 공개 웹사이트에 저장하지 않습니다. 복구 암호의 별도 보관은 소유자가 관리합니다.

Google 인증 자료는 자동 업로드와 복원에만 사용합니다. 백업 내용이나 인증 자료를 광고·판매·AI 모델 학습 목적으로 사용하거나 다른 사람에게 제공하지 않습니다. Google은 Google Drive와 OAuth 서비스를 제공하는 범위에서 해당 정보를 처리합니다.

보존·삭제·연결 해제

백업은 소유자가 정한 보존 정책에 따라 유지합니다. 소유자는 자신의 Drive 백업 폴더에서 자료를 삭제하거나 Google 계정의 연결된 앱 설정에서 접근을 취소할 수 있습니다. 접근 취소만으로 이미 저장한 백업이 자동 삭제되지는 않습니다.

이 정적 안내 사이트는 로그인·분석 스크립트·광고·입력 양식을 사용하지 않습니다. 웹 호스팅 제공자는 자체 서비스 운영 정책에 따른 기본 접속 기록을 처리할 수 있습니다.

English summary

This is a personal, owner-operated utility. It processes selected encrypted backup data, file metadata, storage usage and transfer status solely to back up and restore the owner's data. It requests drive.file, which covers files created by or explicitly authorized for this application, not all existing Drive files. Backup contents are encrypted locally with restic before transfer to the owner's Google Drive. OAuth credentials and recovery passwords are restricted to the owner's devices and are never stored on this public website.

Google user data is not sold, used for advertising or AI model training, or shared with other people. Google processes data as the Drive and OAuth service provider. The owner controls retention and deletion, and can revoke access in Google Account settings. Revoking access does not itself delete existing backups. Use and transfer of Google API information adhere to the Google API Services User Data Policy, including Limited Use requirements. This static site contains no analytics, login or collection forms; the hosting provider may maintain normal access logs.
